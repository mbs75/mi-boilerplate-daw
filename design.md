# Especificación de Diseño Visual - Boilerplate Web DAW

## 1. Concepto e Inspiración
- **Estilo:** Minimalista, tecnológico y limpio, inspirado en la estética de Apple.com (espacios blancos generosos, tipografía definida, contrastes altos).
- **Temática:** Plataforma de presentación de productos o proyectos tecnológicos.

## 2. Paleta de Colores
- `Color Primario (Fondo):` #F5F5F7 (Gris claro Apple)
- `Color Secundario (Tarjetas/Superficie):` #FFFFFF (Blanco puro)
- `Color Texto Principal:` #1D1D1F (Negro mate)
- `Color Texto Secundario:` #86868B (Gris neutro)
- `Color Acento / Interacción:` #0066CC (Azul corporativo)
- `Color Footer:` #111111 (Oscuro de alto contraste)

## 3. Tipografía e Iconografía
- **Fuente Principal:** 'Inter', sans-serif (Google Fonts).
- **Librería de Iconos:** Font Awesome 6.x (CDN).

## 4. Estructura y Dimensiones
- **Ancho del Contenedor Principal:** Mínimo `1000px`, Máximo `2000px` (`width: 90%`).
- **Layout:** Flexbox para alineación horizontal/vertical en cabeceras, rejillas de artículos y pie de página.
- **Unidades:** Absolutas (`px`) para estructura general y límites; Relativas (`rem`, `%`, `em`) para tipografía, espaciados internos de componentes y adaptabilidad.
